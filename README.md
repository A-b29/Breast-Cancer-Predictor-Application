A comprehensive machine learning project that predicts breast cancer risk (Malignant vs. Benign) based on tumor cytological features. This project features a **custom-built Logistic Regression model implemented entirely from scratch** (no scikit-learn) and a premium, modern web interface built with Streamlit.

## ✨ Features

- **Custom Machine Learning Algorithm:** Logistic Regression built entirely from scratch using NumPy, complete with gradient descent optimization, custom epoch training, and loss tracking.
- **Premium User Interface:** A stunning, dark-mode glassmorphism Streamlit UI with a two-column responsive layout, customized tabs, and dynamic animated result cards.
- **End-to-End Pipeline:** Includes data exploration, preprocessing, model training, artifact generation, and deployment.
- **Real-time Inference:** Adjust 12 different cellular features (mean and worst measurements) via interactive sliders to get instant risk probability scoring.

## 📂 Project Structure

- `logistic_model.py`: Contains the `LogisticRegressionScratch` class. Implements the sigmoid function, custom gradient descent, and probability prediction mechanics.
- `explore.py`: The data pipeline script. Reads the Wisconsin Breast Cancer dataset, handles feature selection, normalizes data, trains the custom model, plots correlation matrices/loss curves, and exports the model artifacts (`.npy` files).
- `app.py`: The frontend Streamlit application. Loads the pre-trained weights and normalization bounds to provide a rich, interactive user experience.
- `*.npy` files: Serialized model weights, biases, and normalization constants (mean, standard deviation, and feature bounds) used by the inference app.

## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed. You will need the following libraries:
```bash
pip install numpy pandas matplotlib streamlit
```

### 1. Train the Model

Before running the application, you must train the model to generate the necessary weight and bias files. Make sure `breast cancer wisconsin dataset.csv` is in your directory.

```bash
python explore.py
```
*This will output model accuracy, precision, and recall to the console, and generate `mean.npy`, `std.npy`, `weights.npy`, `bias.npy`, and `feature_bounds.npy`.*

### 2. Launch the Web App

Once the model is trained and the `.npy` files are generated, you can start the Streamlit application:

```bash
streamlit run app.py
```

This will open a local web server (usually at `http://localhost:8501`) where you can interact with the Cancer Risk Predictor UI.

## 🧠 The Model

The model relies on 12 specific cytological features extracted from the dataset, including:
- Radius (Mean & Worst)
- Perimeter (Mean & Worst)
- Area (Mean & Worst)
- Concavity (Mean & Worst)
- Concave Points (Mean & Worst)
- Fractal Dimension (Mean & Worst)

The custom logistic regression utilizes Binary Cross-Entropy loss and updates weights iteratively via Gradient Descent.
